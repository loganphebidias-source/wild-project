Le CSS ça sert à styliser le HTML, c'est-à-dire à définir l'apparence visuelle des éléments de la page web. Il permet de contrôler les couleurs, les polices, les marges, les espacements, les tailles et bien d'autres aspects du design. En utilisant le CSS, on peut rendre une page web plus attrayante et agréable à utiliser pour les visiteurs.
